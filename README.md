# Done Translations – weboldal

Ügyfélszerzésre optimalizált weboldal egy fordítóiroda számára, admin felülettel.

- **[`frontend/`](frontend/README.md)**: Angular 21 – a weboldal és az admin felület (`/admin`)
- **[`backend/`](backend/README.md)**: Laravel 13 API – árajánlatkérések, e-mailek, admin API

Külön repókban is megvannak: [mate_front](https://github.com/megyerimark/mate_front) és [mate_back](https://github.com/megyerimark/mate_back).
A részletes leírás (fejlesztés, kitöltendő adatok, élesítés, arculat) a két mappa README-jében van.
